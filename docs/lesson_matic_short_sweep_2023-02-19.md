## 0. Простыми словами

1. Был **импульс вверх** (памп).  
2. Цена **сняла хаи** (свип ликвидности лонгов) ~**1.536**.  
3. Появился **отбой** (тень / продажи в кластерах).  
4. **Шорт** со стопом **над** свипом, тейк к синим уровням / базе пампа.  
5. По ходу стоп **подтянули в плюс**.

Это учебный разбор одной сделки, не «кнопка всегда шортить».

## 2. Как торговать по скрипту

Файл: `tradingview/lesson_matic_short.pine`  
Индикатор: **«65 MATIC Sweep»**

| На графике | Смысл |
|---|---|
| Жёлтая свеча | всплеск объёма |
| ▼ | учебный шорт: свип хая + отбой |
| ▲ | зеркальный лонг (свип лоу) — тоже пример |
| Синяя линия | план к тейку |
| «сработало: ТЕЙК» / «не сработало: СТОП» | куда реально |
| НЕ ВХОДИ / ШОРТ СЕЙЧАС | ордер только при **СЕЙЧАС** |

ТФ: **5m / 15m**. UX как SpeedTape / DR Setup.

Алерт: колокол → **65 MATIC Sweep** → Once Per Bar Close → Any alert().
