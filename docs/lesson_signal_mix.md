# 65 Signal Mix — точный сигнал из микса уроков

Файл: [`tradingview/lesson_signal_mix.pine`](../tradingview/lesson_signal_mix.pine)  
Индикатор: **«65 Signal Mix»**

## Зачем

На графике не зоопарк меток, а только:

1. **Сигнал** — ЛОНГ/ШОРТ СЕЙЧАС (или ЖДИ / ОПОЗДАЛ)  
2. **Почему** — список модулей, которые совпали  
3. **Рисунок причины** — зона / трендовая / тень / уровень свипа  
4. **Вход / стоп / тейк** — с ценой, %, R (и оценка маржи × плечо)

Всё остальное считается **в фоне** и только голосует.

## Откуда модули

| Модуль | Источник в репо |
|---|---|
| Свип хая/лоу | `lesson_matic_short.pine` |
| Тормозной бар | `lesson_brake_bar.pine` |
| Speed / плотность | `lesson_speed_tape.pine` |
| DR тень 65% | `lesson_dr_setup.pine` |
| Пробой трендовой | `lesson_trendline_break.pine` |
| Защита / пробой зоны | `lesson_level_defense.pine` |
| Ретест ОБ | `ob_inside_lesson.pine` |
| Слом инсайд | `ob_inside_lesson.pine` |

Плюс идеи из старого `mix_map.pine` (HTF EMA, cooldown, R-тейк) — без спама карты BOS/FVG на экране.

## Точность

Сигнал только если **≥ N модулей** в одну сторону (по умолчанию **2**).  
Опционально фильтр тренда EMA20/50.  
Пауза между сигналами (cooldown).

Чем выше «Мин. совпадений», тем реже и жёстче сигнал.

## Как поставить

1. Pine Editor → вставить весь `lesson_signal_mix.pine` → Save → **Add to chart**.  
2. ТФ **5m / 15m**.  
3. Алерт: Any alert() → Once Per Bar Close.

Старые учебные pine можно оставить отдельно для разбора — этот микс для работы.
