# 65 Signal Mix — точный сигнал из микса уроков + старого mix_map

Файл: [`tradingview/lesson_signal_mix.pine`](../tradingview/lesson_signal_mix.pine)  
Индикатор: **«65 Signal Mix»**

## Зачем

На графике не зоопарк меток, а только:

1. **Сигнал** — ЛОНГ/ШОРТ СЕЙЧАС → **В СДЕЛКЕ** (план висит до стопа / ТЕЙК3) → ЗАКРЫТО; без «ОПОЗДАЛ»  
2. **Почему** — список модулей, которые совпали  
3. **Рисунок причины** — зона Fib / трендовая / FVG / сжатие / уровень  
4. **Вход / стоп / тейк** — с ценой, %, R (и оценка маржи × плечо)

Всё остальное считается **в фоне** и только голосует.

## Точность

Сигнал только если **≥ N модулей** в одну сторону (по умолчанию **2**).  
Опционально фильтр тренда EMA20/50.  
Пауза между сигналами (cooldown).

Чем выше «Мин. совпадений», тем реже и жёстче. Для «как полный микс» можно поставить 2–3; для очень жёстко — 3–4.

## Как поставить

1. Удали старую версию Signal Mix с графика.  
2. Pine Editor → вставить весь `lesson_signal_mix.pine` → Save → **Add to chart**.  
3. ТФ **5m / 15m**.  
4. Алерт: Any alert() → Once Per Bar Close.

Полная визуальная карта по-прежнему в `mix_map.pine` / `mix_map_MIX_as_screenshot.pine` — если нужен разбор структуры. Для входа — этот микс.
