## 0. Простыми словами

Урок про **ликвидность** и как цена её собирает.

1. За хаями и лоями сидят **стопы, тейки, ордера на пробой и на отбой**.
2. Цена часто **протыкает** уровень тенью (собирает ликвидность) и возвращается.
3. Рабочий сетап: **пробой уровня → ретест** (бывшее сопротивление = поддержка для лонга; зеркально для шорта).
4. Либо **свип** (ложный пробой) → вход против свипа после возврата.

ДЗ по чату: взять **3 криптоактива × 3 ТФ** и разметить ликвидность / поведение у уровней.

## 1. Определение ликвидности (схема с урока)

На доске было:

**Что такое ликвидность:**

1. Стопы участников  
2. Тейки участников  
3. Ордера на пробой  
4. Ордера на отбой  

Рядом рисунок: две свечи у горизонтального уровня — вторая **чуть протыкает** хай/линию тенью (снятие) и уходит обратно.  
В круге: стрелки вверх (пробой) и вниз (отбой / фейк) + чёрточки над уровнем = стопы.

В чате уточняли: stop-limit (пример «стоп 20, лимит 22»), **upthrust**, «собрали ликвидность → чаще обратный ход», вход на **ретесте**, если хаи перестают обновляться.

## 2. Сетап A — Пробой + ретест (лонг)

Как на схеме (белый зигзаг вверх):

```
  HH → HH → уровень сопротивления ──────
                    │ пробой (красный бокс)
                    │
              ретест ▼── стрелка «вход»
                    │
                   ↗ дальше вверх к следующим блокам ликвидности
```

**Правила:**
1. Есть горизонтальный уровень (локальный хай / полка).
2. Цена **закрывается** выше уровня (пробой).
3. Ждём **возврат** к уровню сверху.
4. Реакция вверх → **лонг**, стоп под уровнем / под лоем ретеста.
5. Цель — следующая зона ликвидности сверху (на схемах — стопка прямоугольников).

Шорт зеркально: пробой вниз → ретест снизу → шорт.

---

## 3. Сетап B — Свип ликвидности (ложный пробой)

На схеме «тройная вершина»:

```
  хай ≈ хай ≈ чуть выше (свип стопов) 
                    │
                    ▼ резкий уход вниз
              ретест / слом структуры → шорт
```

**Правила:**
1. Несколько касаний сопротивления.
2. Тень/бар **выше** хаёв, закрытие обратно **под** уровнем.
3. Ищем шорт после подтверждения (ретест сломанной структуры / отбой).
4. Стоп над свип-хаем.

Лонг-свип зеркально под поддержкой.

---

## 4. Сложенные блоки / цели

Справа на схемах — **стопка горизонтальных прямоугольников** разной ширины: зоны ликвидности / глубины / следующие цели после пробоя.  
Большой вертикальный бокс = импульсный ход после снятия.

## 6. Как торговать по уроку (чеклист)

1. На выбранном ТФ отметь swing high/low = пулы ликвидности.  
2. Жди либо **чистый пробой + ретест**, либо **свип + возврат**.  
3. Вход на ретесте / после подтверждения, не в середине импульса без уровня.  
4. Стоп за уровнем / за свип-экстремумом.  
5. Цель — следующий пул ликвидности.  
6. ДЗ: 3 актива × 3 ТФ — разметить то же самое руками.
