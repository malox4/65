## 1. Коротко: что это за подход

Это **ручной Price Action / Smart Money** учебный каркас, не индикаторный робот:

1. Найти **ликвидность** (где сняли / ещё снимут стопы).
2. Дождаться формации **инсайд-бар** или **классический order block (ОБ)**.
3. Дождаться **импульса / слома** структуры.
4. Входить предпочтительно на **ретесте блока**, стоп — за противоположным краем зоны.
5. На живом рынке подтверждать картинку **дельтой / footprint / профилем** (скальп-слой).

Инструменты на записи: TradingView (ru), вкладки TensorCharts / ScalpStation, order-flow терминал (кластеры, delta, speed of tape, volume profile).

Пары в примерах: **BTCUSDT**, **LTCUSDT**, **XRPUSDT** (фьючи). ТФ теории: **1H**; практика: **4H / 1H / M15 / 5s**.

## 2. Словарь урока

| Термин | Смысл в уроке |
|---|---|
| **Ликвидность** | Скопления стопов за локальными high/low; «собрали» vs «ещё есть» |
| **Снятие стопов** | Тень свечи прокалывает уровень и цена возвращается |
| **Mother / инсайд-бар** | Широкая свеча + следующая целиком внутри её high–low |
| **Слом инсайд-бара** | Закрытие (импульс) за диапазон mother |
| **Классический ОБ** | Зона последней встречной свечи / блока перед сильным импульсом |
| **Вход** | Ретест края зоны (на схеме лонга — **верх** белого бокса) |
| **Стоп** | За противоположным краем зоны (на схеме лонга — **низ** бокса) |
| **Крупный игрок** | Набор позиции через снятие ликвидности и зоны спроса/предложения |

## 3. Ядро сетапа A — Классический ОБ

Как нарисовано на схемах (подписи **«Классический ОБ»**, **вход**, **стоп**):

```
  LH → LH → LH          даунтренд / серия LL+LH
       ┌────────────┐
       │  ОБ (бокс) │   ← зона последней базы / встречной свечи
       │   ▼ sweep  │   ← часто тень ниже бокса (снятие)
       └────▲───────┘
            │
         ████████      ← сильный импульс вверх (слом)
            │
     ретест ▼── вход по верхней границе бокса
              ── стоп под нижней границей бокса
```

### Правила (лонг; шорт зеркально)

1. Есть нисходящая (или встречная) структура.
2. Формируется зона консолидации / последняя медвежья свеча.
3. Желателен **sweep** — прокол низа тенью.
4. Появляется **импульсная** бычья свеча, уходящая из зоны вверх (слом).
5. **Не гнаться** за импульсом: ждать возврат цены к зоне.
6. **Лимит / вход** у верхней границы ОБ.
7. **Стоп** под нижней границей ОБ (+ небольшой запас допустим).
8. Цель — структура выше (предложение, предыдущие хаи, R-кратность). На схемах явной фиксированной формулы TP не было; в Pine по умолчанию **2R**.

## 4. Ядро сетапа B — Инсайд-бар → ОБ

Подписи на схемах: **«ИНСАЙД БАР»**, **«СЛОМ ИНСАЙД БАРА = КЛАССИЧЕСКИЙ ОБ»**.

```
  Mother (широкая)
  ┌──────────────┐
  │   Inside     │  ← high/low внутри mother
  └──────┬───────┘
         │
      █████████      ← слом вверх за high mother
         │
   бокс mother(/inside) дальше = ОБ → ретест / стоп как в §3
```

### Правила

1. Свеча N — **mother**.
2. Свеча N+1 — **inside**: `high < mother.high` и `low > mother.low`.
3. Свеча N+2 (или позже) **ломает** диапазон mother импульсом.
4. После слома диапазон (на схемах — белый прямоугольник вокруг mother±inside) трактуется как **классический ОБ**.
5. Дальше та же логика: **ретест блока**, стоп за противоположной стороной.

### Открытый нюанс из чата (важно)

Ученик **christmas**: *«После слома инсайд бара блок рисуем по телу этого инсайд бара?»*

На схемах бокс охватывает **весь диапазон mother** (high–low), не только тело inside.  
В скрипте зона = **high/low mother**. Если преподаватель ответил «только тело inside» — это уточнение голосом; по видео-схемам зафиксирован диапазон mother.

Ученик **Evgeniy**: *«Точка входа при ретесте в блок? Или сразу на развороте?»*

На схемах акцент на **ретесте** (стрелка «вход» к краю бокса после импульса), не на market-входе в момент слома.

## 5. Ликвидность (обязательный слой)

Закреп ДЗ в группе **«10 поток»** (дословно по смыслу):

> Взять **3 разных криптоактива** и на **3 разных ТФ** выделить ликвидность, которую **собрали** и которая **ещё есть**.  
> Найти уровни, где **тенью были сбиты стопы** (отметить блоком зону свечи).

Практический чеклист:

- [ ] Локальные swing high/low — где стоят стопы толпы
- [ ] Уже снятые уровни (длинная тень + возврат) vs нетронутые
- [ ] Зона свечи-охотника помечена боксом
- [ ] Несколько ТФ: старший задаёт «где», младший — «когда»

На схемах начала урока: зелёные чёрточки под тенями = стопы / ликвидность; круг на «дне» = зона разворота после снятия.

## 6. Demand / Supply на практике (LTC и др.)

На живых графиках LTCUSDT:

- **Demand (зелёный бокс)** снизу — отскок / набор лонга после захода в зону.
- **Supply (серый/жёлтый бокс)** сверху (~100.5–103.5 на LTC 4H в примере) — сопротивление / зона для шорта или тейка лонга.
- После импульса вверх цена часто **возвращается** тестировать зону; слом зоны + негативная дельта усиливает шорт-сценарий.

Это тот же принцип ОБ, только зона может быть шире одной свечи (область базы).

## 8. Order-flow / скальп-слой

Отдельный кусок записи — не замена ОБ, а **микро-подтверждение**:

- Footprint / кластеры: объём покупок / продаж в цене.
- **Delta** (в т.ч. дивергенция цена↑ / delta↓).
- **Volume Profile** — HVN, POC, суммарная дельта.
- **Speed of Tape** — всплеск скорости ленты на снятии / импульсе.
- Пример: **XRPUSDT** Binance Futures, ТФ **5 секунд**.

Логика связки:

```
Старший ТФ: ликвидность + ОБ/IB + направление
     ↓
Младший ТФ / DOM: delta, кластер, tape → момент входа в зоне
```

## 10. Алгоритм «как торговать по уроку» (чеклист)

### Подготовка
1. Выбрать актив + 3 ТФ (как в ДЗ).
2. Разметить собранную и оставшуюся ликвидность.
3. Отметить тени со снятием стопов боксами.

### Поиск сетапа
4. Найти **IB** или базу под **классический ОБ**.
5. Дождаться **импульса / слома** в сторону сделки.
6. Зафиксировать бокс зоны (mother range или последняя встречная свеча).

### Вход
7. Ждать **ретест** зоны (предпочтительно).
8. Вход у «рабочего» края (лонг — верх зоны, шорт — низ).
9. Стоп за противоположным краем.
10. Опционально: CCI/MACD/дельта/кластер не противоречат.

### Управление
11. Тейк к следующей ликвидности / supply-demand / R-кратности.
12. Если закрытие за стоп-краем зоны — сетап снят.
