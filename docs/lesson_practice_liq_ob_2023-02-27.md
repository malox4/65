## 0. Простыми словами

На графике размечают:

1. **Зелёные уровни** — ликвидность **ещё не снята** (туда можно целиться / ждать прихода цены).  
2. **Красные уровни** — ликвидность **уже снята** (проткнули и ушли).  
3. **Классический ОБ** и **инсайд-бар** — зоны интереса для входа после импульса.  
4. **Пробой → ретест** уровня / инсайд-блока — рабочий вход.  
5. Подтверждение: **Volume Delta**, дивергенции, на DeltaRiver — кластеры / POC / impulse.

## 2. Сетапы, которые повторяли

### A. Ликвидность
- Swing high/low = пул.  
- Касание/прокол → уровень становится «снятым» (красный).  
- Ближайшая **зелёная** ликвидность по ходу сделки = ориентир тейка.

### B. Классический ОБ + инсайд
Как 20.02: импульс от зоны → зона = ОБ; инсайд → слом = ОБ; вход предпочтительно на **ретесте**.

### C. Пробой + ретест (MATIC и др.)
На MATIC 15m: **инсайд-блок** → пробой уровня ~1.26 → метка **РЕТЕСТ** → продолжение.  
Тейк к следующей горизонтали (~1.30).

### D. Order flow / кластеры (BTC)
DeltaRiver / ATAS: cluster search, POC, speed of tape, delta, volume profile.  
Жёлтые зоны / зелёный HVN = уровни; смотрят H1 + M15 вместе.

## 4. Как торговать по этому уроку

1. Разметь **неснятую** ликвидность (зелёная).  
2. Найди **ОБ / инсайд** на пути цены.  
3. Жди **пробой** структуры или уровня.  
4. Вход на **ретесте** (не вдогонку импульса).  
5. Стоп за зоной ОБ / за уровнем.  
6. Тейк к ближайшей **зелёной** ликвидности по направлению.  
7. Опционально: дельта/кластер не противоречит (нет сильной встречной дельты на входе).
