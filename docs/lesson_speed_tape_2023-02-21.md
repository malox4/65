## 0. Простыми словами

Урок учит смотреть **не только объём**, а **скорость ленты** (как часто идут сделки) вместе с **дельтой** и **зоной**.

1. Разметь зону (сопротивление / поддержка / Value Area / POC).  
2. Жди бар, где **Speed of Tape** резко ускорился **и** есть пик **Volume**.  
3. Смотри **Delta**: с движением = импульс; против / после климакса у края зоны = намёк на **разворот**.  
4. H1 = контекст, M15 = подтверждение, **5s** = момент входа (на ATAS).

На TV настоящего Speed of Tape нет — скрипт даёт **суррогат плотности** (объём / диапазон свечи) + объём + грубая дельта.

## 2. Правила разворота vs продолжения

| Жди **разворот** | Жди **продолжение** |
|---|---|
| Пик Speed + Volume **у края зоны** (VAH / сопротивление / поддержка) | Speed + Volume + Delta **в сторону** импульса |
| Delta встречная или после климакса | Цена удерживает направление |
| Цена **не держит** пробой зоны | Зона пробита с сопровождением дельты |

Пример с урока (H1, ~16.02.2023 00:00): у верхней зоны tooltip **Maximum Speed ≈ 2.59M** + объём → дальше откат вниз от зоны.

Пример (M15, ~16.02 ~22:15): жёлтый Speed + длинный **красный Delta** → пробой вниз к нижней границе диапазона.

Пример (20.02 день): Speed + Volume + **зелёный Delta** → импульс вверх в зону; на пике часто отказ/консолидация.

## 3. Как торговать по скрипту

Файл: `tradingview/lesson_speed_tape.pine`  
Индикатор: **«Урок · Speed of Tape»**

| Статус | Действие |
|---|---|
| **ЖДИ** | нет свежего климакса у свинга |
| **ЛОНГ / ШОРТ СЕЙЧАС** | плотность+объём у локального низа/верха + 1 вход / 2 стоп / 3 тейк |
| **ОПОЗДАЛ** | не догоняй |
| Метки **пример↑/↓** | учебные; пунктир = план, подпись = куда реально (тейк/стоп/мимо) |

ТФ: **15m / 1H** (как на уроке). Порог плотности подстраивай под монету.

Алерт: колокол → этот индикатор → **Once Per Bar Close** → **Any alert() function call**.

## 4. Ограничения

- TV **не** видит тиковую ленту ATAS — «скорость» = прокси `volume / range`.  
- Delta на TV — грубая (направление тела / объём), не Filter=50 ATAS.  
- 5-секундный ТФ на TV для учебы неудобен; логику отрабатывай на M15/H1.  
- Треугольники на истории = **примеры**, не ордера.
