## 0. Простыми словами (что делать тебе)

Урок крутится вокруг **уровня** (зона объёма / POC / серый бокс на графике) и двух сценариев:

1. **Защита уровня лимитником** — крупный игрок **держит** зону лимитами. Ты ждёшь **отбой** от зоны → вход в сторону удержания, стоп за зоной.
2. **Вход после того, как цена уйдёт под** (или над) уровень — уровень **сломали**. Вход **после** ухода за зону (не «угадывать» пробой заранее), стоп обратно в зону / за экстремум.

Параллельно на DeltaRiver:

- режим **«объем полный + дельта»**;
- **POC автоуровни** H4 / D1 / W1 (разные цвета линий);
- DOM-фильтры крупных одиночных ордеров (Ask/Bid пороги);
- в Autotrade: стратегии **«Нехочуха»** (CCI) и **«Поглощение»**.

Индикатор на TV — **план сделки с именами линий**, не копия DeltaRiver.

## 2. Главная схема урока: защита vs пробой

На кадре (~20 мин) зелёная подпись на DeltaRiver:

> **«Защита уровня Лимитником / Вход — после того, как цена уйдет под»**

| Сценарий | Что видишь | Действие | Стоп | Тейк |
|---|---|---|---|---|
| **Защита (лимит)** | Цена подходит к зоне, отскакивает, кластер/дельта «держит» | Лимит / вход от зоны **в сторону удержания** | За противоположный край зоны (+ запас ATR) | Ближайшая противоположная зона / POC / R× |
| **Пробой (ушла под/над)** | Закрытие **за** зоной, зона перестаёт держать | Вход **после** ухода (не до) | Обратно в зону / за свинг | Следующий POC / дальность диапазона |

Красная двусторонняя стрелка на уроке = **диапазон между верхней и нижней серой зоной** — ориентир размера хода / TP.

## 3. POC автоуровни (H4 / D1 / W1)

В Options → **Point of Control (автоуровни)** на уроке включены:

- **H4**, **D1**, **W1** (галочки);
- у каждого ТФ свой цвет линии.

Смысл: горизонтали **максимального объёма** на старшем периоде — магниты и ориентиры для защиты/пробоя.  
На TV настоящий tick-profile POC нет — в скрипте: **прокси POC** = цена бара с максимальным объёмом на окне старшего ТФ (H4/D1/W1).

Имена на графике:

- `POC H4`
- `POC D1`
- `POC W1`

## 4. Autotrade на уроке (концепт, не копировать слепо)

### 4.1 «Нехочуха»

- Условия по **CCI** (пороги вроде `CCI <= -150` / глубже `-250` и зеркально для продаж).
- Чекбоксы объёма: общий ↑, инициативный ↑, противоположный ↓.
- Окно часов торговли 0–23.
- Buy/Sell тумблеры, объём ордера, SL/TP.

### 4.2 «Поглощение»

- Наличие тренда, объём, дивергенция.
- Тип поглощения: полное / тело.
- Это **фильтр свечи**, не отдельная «вселенная».

На TV в `lesson_level_defense.pine`:

- опциональный фильтр **CCI** (как на графиках урока: CCI 30, уровни ±200 / ±300);
- сигнал **поглощения** (engulf) рядом с рабочей зоной;
- MACD_LB(5,34,5) в доке урока на TV-кадрах — опциональный контекст, в скрипте не обязателен.

## 5. DeltaRiver-настройки, которые мелькали

| Блок | Что ставили / смотрели |
|---|---|
| Режим свечи | `объем полный + дельта` |
| Пользовательский фильтр объёмов | как на 03.03 (дельта в тенях) |
| DOM | фильтр одиночного ордера (пример на кадре: Ask 10 / Bid 500 — **под монету**) |
| Cumulative Delta Day | нижняя панель |
| CCI / RSI / Stoch / ATR | рядом с дельтой |
| ТФ разбора | M15 (ДЗ), H1 (кластеры/ступеньки POC), зоны на старших |

Pine **не** эмулирует DOM и одиночные ордера стакана.

## 6. Как торговать по скрипту `lesson_level_defense.pine`

Файл: `tradingview/lesson_level_defense.pine`  
Индикатор: **«Урок · Защита уровня»**

1. Pine Editor → вставить весь файл → Save → Add to chart.
2. ТФ **15m** (ДЗ) или **1H** (как разбор кластеров на уроке).
3. Смотри **одну** активную зону + таблицу справа.

### Что нарисовано (с именами)

| Линия / метка | Смысл |
|---|---|
| `ЗОНА ВЕРХ` / `ЗОНА НИЗ` | Рабочий диапазон уровня (серый бокс) |
| `POC H4` / `POC D1` / `POC W1` | Прокси автоуровней |
| `ЗАЩИТА · ЛОНГ/ШОРТ` | Сценарий отбоя от зоны |
| `ПРОБОЙ · ВХОД` | Сценарий после ухода за зону |
| `ВХОД` / `СТОП` / `ТЕЙК` | План сделки |
| `ПОГЛОЩЕНИЕ` | Engulf у зоны (фильтр) |

### Фазы

1. **Жди цену у зоны** — бокс есть, входа нет.  
2. **Защита** — отбой + (опц.) поглощение/CCI → линии вход/стоп/тейк.  
3. **Пробой** — закрытие за зоной → новый план в сторону пробоя.  
4. Один активный план; спама меток нет.

## 8. Чеклист перед входом

1. Есть ли **именованная зона** (не «любая линия»)?  
2. Это **защита** (отбой) или **пробой** (ушла за зону)?  
3. Есть ли **POC** старшего ТФ рядом как магнит / цель?  
4. Стоп **за** зоной, тейк к противоположной зоне / R?  
5. На альте из ДЗ — сверил ли кластер (03.03), а не только PA?
