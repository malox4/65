## 0. Простыми словами

На кадре урока две подписи:

1. **Реакция на объёмный уровень** — настройка общего объёма в кластерах. Смотри, где накопился объём; жди реакцию цены у этого уровня.  
2. **Лимитный игрок** — кто стоит лимитом:  
   - **верхняя часть свечи → покупки** (агрессивные байи);  
   - **нижняя часть свечи → продажи**.  
   Если вверху огромные покупки, а цена **не ушла выше** — лимитный **продавец** съел бай.  
   Если внизу огромные продажи, а цена **не ушла ниже** — лимитный **покупатель** съел селл.

Не входи «в воздухе». Вход у объёмного уровня / после реакции лимитника.

## 3. POC / VAH / VAL (ответ на вопрос из чата)

| Термин | Смысл |
|---|---|
| **POC** | цена с **максимальным** объёмом в окне |
| **VAH** | верх Value Area (~70% объёма) |
| **VAL** | низ Value Area |

Это **не** «средний максимум», а зоны профиля. На TV скрипт рисует прокси POC + VAL/VAH по объёму баров окна.

## 4. Как торговать по скрипту

Файл: `tradingview/lesson_limit_volume.pine`  
Индикатор: **«Урок · Лимит+Объём»**

| Статус | Действие |
|---|---|
| **ЖДИ** | нет реакции у уровня / лимитника |
| **СЕЙЧАС** | есть вход / стоп / тейк на линиях |
| **ОПОЗДАЛ** | не догоняй |

| Метка | Смысл |
|---|---|
| `ОБЪЁМНЫЙ УРОВЕНЬ` | POC окна |
| `VAL` / `VAH` | края value area |
| `ЛИМИТ ПОКУПАТЕЛЬ` | лонг: продажи внизу съели, отбой |
| `ЛИМИТ ПРОДАВЕЦ` | шорт: покупки вверху съели, отбой |

ТФ: **15m**. Порог объёма подстроить под монету.
