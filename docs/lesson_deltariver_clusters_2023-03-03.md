## 3. Ядро стратегии

### 3.1 Что смотрят

1. **Кластерная свеча** в режиме `объем полный+дельта` (или `объем+полный+дельта`).
2. **Пользовательский фильтр объёмов** — подсветка ячеек footprint, где объём/дельта ≥ порога.
3. Место фильтра в свече: **верхняя тень** vs **нижняя тень**.
4. **Cumulative Delta Day** — дневной CVD / гистограмма дельты.
5. **POC бара** (максимальный объём в баре), профиль по цене, вертикальный объём.
6. Снятие ликвидности (sweep) + всплеск объёма на экстремуме.
7. Опционально: Zoner, ZigZag, Bollinger, Big Trades, CCI.

### 3.2 Типовые фильтры с урока (ADA M15)

Из окна настроек на кадрах (значения **зависят от монеты**):

| Условие | Где | Цвет | Смысл |
|---|---|---|---|
| Покупки дельта ≥ ~400k–600k | **Верхняя тень** бара | Зелёный | Buy climax / absorption сверху (часто на **медвежьей** свече) |
| Продажи дельта ≥ ~70k–500k | **Нижняя тень** бара | Красный | Sell climax / absorption снизу |
| Общий объём (на LINK и др.) | Ячейка кластера | Синий | Крупный узел объёма |

На **LINK** пороги были порядка **~18k** дельты / **~16k** общего — порог **не универсальный**, его подбирают под тикер (как жаловались в чате про ADA).

Доп. галки в опциях на кадрах:
- Imbalance auto-color;
- тип бара «Медвежий» для buy-delta в верхней тени;
- уведомление по фильтру.

### 3.3 Торговая идея (как собирается сетап)

```
Старший контекст (H4/H1): зона / heatmap / уровень интереса
        ↓
M15 footprint: экстремум + всплеск объёма
        ↓
Фильтр в тени:
  • SellΔ в нижней тени (+ sweep низа) → идея ЛОНГ (поглощение продаж)
  • BuyΔ в верхней тени (+ sweep верха) → идея ШОРТ (поглощение покупок)
        ↓
Подтверждение: CVD day, дельта бара, POC, лимитный интерес
```

Это **не** «торговать каждый квадратик фильтра». Квадратик = *место, где был крупный поток*; вход — когда он совпадает с ликвидностью / зоной / разворотом CVD.

## 6. Алгоритм «как делать ДЗ / как торговать по уроку»

### Подготовка
1. Выбрать альт **не BTC/ETH**.
2. Открыть **M15**, режим полный объём + дельта.
3. Подобрать пороги фильтра так, чтобы подсветка была **редкой, но читаемой** (не весь график в квадратах).
4. На H4/H1 отметить крупные зоны / heatmap (как советовали в чате).

### Поиск
5. Искать **sweep** локального high/low + аномальный объём.
6. Смотреть, есть ли в **тени** экстремума ячейка с BuyΔ (верх) или SellΔ (низ) выше порога.
7. Сверить с **CVD day** и дельтой бара (климакс → разворот дельты).
8. Отметить POC / профиль как уровень возврата.

### Вход / риск (как следует из логики урока, без жёстких цифр RR)
9. Лонг: после sell-climax внизу, стоп за лоем снятия.
10. Шорт: после buy-climax вверху, стоп за хаем снятия.
11. Цель — следующая зона / противоположная ликвидность / POC профиля.

## 7. Что скрипт делает на TradingView

Файл: `tradingview/deltariver_clusters_lesson.pine`  
Индикатор: **«Урок · Кластеры DeltaRiver»**

| Фича | Соответствие уроку |
|---|---|
| LTF split buy/sell volume | Прокси footprint-дельты |
| BuyΔ в верхней половине бара | Фильтр «покупки дельта → верхняя тень» |
| SellΔ в нижней половине | Фильтр «продажи дельта → нижняя тень» |
| Квадраты над/под свечой | Подсветка срабатывания фильтра |
| ▲/▼ сигнал | Фильтр + объём×SMA + опциональный sweep |
| POC бара | Макс. объём LTF-ячейки |
| CVD Day | Cumulative Delta Day |
| Бокс зоны | Уровень интереса на сигнале |
| Таблица | BuyΔ верх / SellΔ низ / Δ / CVD / POC |

### Как поставить
1. Pine Editor → вставить файл → Save → Add to chart.
2. ТФ: **15m** (как ДЗ). LTF по умолчанию **1m**.
3. **Обязательно** подстроить `Покупки дельта ≥` и `Продажи дельта ≥` под монету (на BTC/ETH объёмы другие; на мелких альтах — меньше).

### Ограничения прокси
- TV не даёт настоящий bid/ask footprint DeltaRiver.
- Деление объёма по close внутри LTF-бара — оценка, не биржа.
- Пороги с урока (400k/500k) калиброваны под **ADA perpetual** того периода; на 2026 других монетах пересчитай.
