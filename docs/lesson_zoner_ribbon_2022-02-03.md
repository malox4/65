## 0. Простыми словами

Три слоя на уроке:

1. **Тренд на TV** — лента EMA / TEMA + RSI. Не входи против явной ленты, пока не понял структуру.  
2. **Зоны руками** — красный прямоугольник сверху (сопротивление / цель продаж), зелёный снизу (поддержка / зона покупок). Схема пути цены (зигзаг) — сценарий, не гарантия.  
3. **В DeltaRiver** — объёмный профиль, дельта, **фильтр объёма в тенях** и **Zoner** (% уровни от импульса со стопами).

## 2. DeltaRiver — фильтр в тенях (важно)

Пользовательский фильтр на уроке:

| Условие | Где | Смысл |
|---|---|---|
| Продажи `>= ~75` | **нижняя тень** | сильные продажи внизу свечи |
| Покупки `>= ~80` | **верхняя тень** | сильные покупки вверху свечи |

Логика та же, что позже назвали **лимитным игроком**:  
продажи внизу + цена не упала → думаем про **поглощение / лонг**;  
покупки вверху + цена не ушла → **поглощение / шорт**.  
Пороги под монету.

Также: профиль объёма по цене, режим **дельта**, POC-F / POC-D, шаблоны сохранить/загрузить.

## 3. Zoner (% зоны)

Настройки с кадра:

| % | Метка на уроке |
|---|---|
| −20% | СТОП |
| 0% | база / старт (X) |
| 30% / 50% / 90% | промежуточные |
| 100% | цель (X) |
| 120% | СТОП (за целью) |

Zoner = измерить **импульс** и разложить путь на проценты: где вход (около 0), где тейки (50–100), где стоп (−20 или за 120).

## 4. Как торговать по скрипту

Файл: `tradingview/lesson_zoner_ribbon.pine`  
Индикатор: **«Урок · Zoner+Лента»**

| На графике | Смысл |
|---|---|
| Лента EMA | направление |
| `ЗОНА СОПР` / `ЗОНА ПОДД` | красная / зелёная зона |
| линии `0% … 100%` + стопы | Zoner от последнего импульса |
| статус ЖДИ / СЕЙЧАС / ОПОЗДАЛ | когда можно входить |
| `пример отбой ↑/↓` | учебные метки фильтра в тенях |

Правило: **ордер только при «СЕЙЧАС»**. Треугольники на истории — примеры.

ТФ: **1H** (как TV-часть) или **15m** (как DeltaRiver).
