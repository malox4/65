# 65 Signal Mix PRO — сигнал с режимом, риском и своей статистикой

Файл: [`tradingview/signal_mix_pro.pine`](../tradingview/signal_mix_pro.pine)  
Индикатор: **«65 Signal Mix PRO»**

Это ответ на вопрос «чего не хватает Signal Mix для торговли». Не обещание прибыли: индикатор **измеряет сам себя** и говорит, можно ли ему верить.

---

## Что добавлено по сравнению с `lesson_signal_mix.pine`

| Было не хватало | Как закрыто в PRO |
|---|---|
| Контекст рынка | **Режим**: тренд 4h (EMA20/50), **BTC 1h** по ходу, **ATR-ранг** ≥ порога, опц. окно сессии |
| Независимые голоса | Сигнал = **структура ≥1** **И** **поток ≥1** (разные оси), а не сумма похожих меток |
| Риск | **Стоп в коридоре % цены** (по умолчанию 0.5–2.5%), TP1/TP2 в R, одна сделка, пауза после сделки |
| Исполнение | Статус **СЕЙЧАС только на баре сигнала**; потом **В СДЕЛКЕ** до стопа / TP2 / горизонта; нет «входа вдогонку» |
| Статистика своих сигналов | Встроенный форвард-учёт: **N, в плюс %, средний R, кумулятивный R, просадка в R, серия минусов** |
| Решение «можно ли» | **Вердикт** из статистики: мало данных / статистика ОК / край не подтверждён |
| Размер позиции | В подписи: позиция ≈ риск% ÷ стоп% (и эквивалент плеча) |

## Четыре слоя (все обязательны)

### 1. Режим
- `4h` EMA20 > EMA50 для лонга (и наоборот)  
- `BTC 1h` EMA20 > EMA50 для лонга  
- ATR-ранг (percentrank ATR% за окно) ≥ 60% — монета «живая»  
- Опционально: только в окне сессии (UTC)

### 2. Структура (нужен хотя бы один)
Свип экстремума · пробой уровня + ретест · ОБ импульс + ретест · пробой трендовой (с объёмом).  
Стоп берётся **от структуры** (за свип-лоу / за ОБ), не от произвольного ATR.

### 3. Поток / свеча (нужен хотя бы один)
Тормоз (тень ≥55% + объём) · DR (тень ≥65%, тело ≤90%) · плотность volume/range · поглощение с объёмом.

### 4. Риск-гейт
Стоп в % цены внутри коридора → иначе сигнала нет, даже если всё остальное совпало.

## Статусы

| Статус | Смысл | Что делать |
|---|---|---|
| **ЖДИ** | нет полного совпадения | ничего; в подписи видно, какой оси не хватает |
| **ЛОНГ / ШОРТ СЕЙЧАС** | бар сигнала закрылся | лимит/рынок у входа, стоп и TP с подписи |
| **В СДЕЛКЕ** | план висит | не добавлять, не двигать стоп против |
| **ИТОГ** | закрыто: TP2 / стоп / время | записать в журнал |

Если ты пропустил СЕЙЧАС — **следующего входа в эту сделку нет**. Это специально.

## Как читать вердикт

| Вердикт | Условие (настройки) | Действие |
|---|---|---|
| **МАЛО ДАННЫХ · только бумага** | сделок < 30 | торговать только на бумаге / демо |
| **СТАТИСТИКА ОК · малый риск** | средний R ≥ 0.10 и просадка ≤ 8R | можно пробовать 0.5–1% риска |
| **КРАЙ НЕ ПОДТВЕРЖДЁН · не деньгами** | иначе | не торговать деньгами, менять настройки/монеты |

Статистика считается **на том графике и ТФ, где стоит индикатор** — от первой свечи истории. Меняешь монету/ТФ/настройки — статистика другая. Это и есть твой бэктест прямо на TradingView.

---

## Честно: что индикатор НЕ гарантирует

- Что статистика на истории повторится вперёд (переподгонка настроек под монету — реальный риск).  
- Что исполнение будет по цене входа (спред, проскальзывание, комиссии в статистике **не** учтены — закладывай ~0.1–0.2R на сделку сам).  
- Что на TV есть настоящий поток (DOM/footprint) — слой 3 это прокси по свече.  
- Что «СТАТИСТИКА ОК» = можно лить депозит. Это разрешение на **малый** риск, не на плечо.

**Уверенность** появляется так: ≥30 сделок на бумаге по этому индикатору с положительным средним R и приемлемой просадкой, затем маленький реальный риск, затем сравнение журнала с таблицей.

## Как поставить

1. Pine Editor → вставить весь `signal_mix_pro.pine` → Save → **Add to chart**.  
2. ТФ **15m** (режим на 4h и BTC 1h подтягивается сам).  
3. Дать истории прогрузиться — таблица покажет N сделок и вердикт.  
4. Алерты: колокол → **65 Signal Mix PRO** → **Once Per Bar Close** → `Any alert() function call`.  
5. Торговать **только** при СЕЙЧАС и только пока вердикт не «не деньгами».

## Настройки, которые имеет смысл крутить

- `Мин. ATR-ранг` — 50–75; выше = реже, чище.  
- `Мин./макс. стоп %` — под монету (BTC 0.3–1.5, альты 0.5–3).  
- `TP2` — 1.5–2.5R; при 2R нужно >33% попаданий до комиссий.  
- `Пауза` — 8–20 свечей, чтобы не брать серию на одном движении.  
- Отключай отдельные модули, чтобы увидеть, кто тянет статистику вниз.
