## Потенциальная свеча

Вкл/выкл: настройка **«Потенциальная свеча»** (группа Entry).

| Когда | Что показывает |
|---|---|
| Ждём пробой сжатия / шеи | Типичная свеча пробоя по размеру ~ATR |
| Только что сработал вход | Тело к ~1R, фитили к стопу и цели |

Это **иллюстрация сценария**, не прогноз и не гарантия. Число ордеров в стакане Pine не видит — намеренно не рисуем.

## SK Fib (откат по тренду)

Сетап из разбора видео: импульс → откат в зону Fib 0.5–0.786 → разворотная свеча → вход по импульсу.

| Шаг | Как считает скрипт |
|---|---|
| Импульс | high/low за `Импульс: свечей назад` (40), размах ≥ `Мин импульс в ATR` (3) |
| Направление | low позже high → импульс вниз (шорт); иначе вверх (лонг) |
| Зона | фиолетовый бокс 0.5–0.786 от импульса, тянется до текущей свечи |
| Триггер | свеча закрылась в зоне + медвежье/бычье поглощение или пин-бар ≥55 % диапазона + 4h по направлению |
| Стоп | за край зоны 0.786 (или за экстремум свечи) + 0.1 ATR |
| TP1 / TP2 | расширение 1.272 / 1.618 от импульса |

Строка **SK Fib** в правой таблице показывает состояние: «ждём откат в зону», «в зоне · ждём свечу», «импульса нет».

## Карточка «План входа»

Внизу справа — одна точка подсказки, общая для всех сетапов (SK Fib, BOS/CHoCH, двойное дно/вершина, сжатие):

```
ПЛАН: ЛОНГ      SK Fib лонг
Вход            2364.9
Стоп            2358.2
Тейк 1          2397.4
Тейк 2          2410.1
R:R / стоп %    4.9R · 0.28%
Свечей назад    0
```

Пока сигнала нет — «ПЛАН ВХОДА · сигнала нет» и что «ждём». План держится 8 свечей после сигнала, потом гаснет.
Алерты: `Potential long/short`, `SK Fib long/short`, `Any plan` (любой готовый план).

## Сервис (локальный график)

Та же карта считается в `bot/smc_map.py` и отдаётся в `/api/strategy/coin` как поле `map`:
`levels`, `events`, `boxes`, `pending`, `fib` (зона и состояние SK Fib), `ghost`, **`plan`**.

`plan` — единая подсказка «что делать»:

| Поле | Смысл |
|---|---|
| `status` | `enter` — сигнал на закрытой свече; `wait` — есть сценарий, ждём триггер; `none` |
| `side`, `name` | ЛОНГ/ШОРТ и сетап (SK Fib откат, BOS/CHoCH, двойное дно/вершина, пробой сжатия) |
| `entry`, `stop`, `tp1`, `tp2` | уровни; для `wait` — где вход *будет*, если триггер сработает |
| `rr`, `stopPct`, `why` | R:R до TP1, стоп в % цены, пояснение |

На спот-графике: фиолетовая зона SK Fib, карточка «План входа» в панели алерта (зелёная/красная рамка = входить сейчас, пунктир = ждём),
линии «план вход / стоп / тейк» на шкале цен.

Бумажный бот берёт `plan.status == "enter"` (не старше 2 свечей 15m) как кандидата наравне с объёмными паттернами — TP = `tp1`.
Основа по-прежнему микс A+B+C с фильтрами; SK Fib добавлен для набора статистики, не как «проверенный край».

## Ограничения

- Карта разметки на TV и в сервисе — не полная копия фильтров бота.
- В исследовании одиночные паттерны после комиссий были в минусе; микс с фильтрами — слабый край.
