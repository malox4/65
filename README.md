# 65

Личный сервис рыночных алертов и торговых решений.

План и алгоритм работы: [PLAN.md](PLAN.md).

Свечи берутся с публичного спота Binance, пара `BTCUSDT`, таймфрейм `1h`. Ключ биржи для этого не нужен.

```bash
python -m bot
```

Команда сохраняет закрытые свечи в `data/market.db` и печатает последние пять.

График в браузере, в цветах Binance, на тех же публичных свечах:

```bash
python -m bot.server
```

Страница открывается на http://127.0.0.1:8765. На ней спот и фьючерсы USDT-M, таймфреймы от 1 минуты до 1 месяца. Свечи и объём рисует библиотека TradingView Lightweight Charts, источник котировок — Binance.
