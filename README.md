# 65

Личный сервис рыночных алертов и торговых решений.

План и алгоритм работы: [PLAN.md](PLAN.md).

Свечи берутся с публичного спота Binance, пара `BTCUSDT`, таймфрейм `1h`. Ключ биржи для этого не нужен.

## На своём ПК

Сервер должен работать **на вашем компьютере**, не в облаке. Иначе Chrome на `localhost` покажет `ERR_CONNECTION_REFUSED`.

1. Склонируйте или обновите репозиторий.
2. Запустите сервер из корня проекта:

```bash
# Windows — двойной клик по start.bat или:
start.bat

# macOS / Linux:
chmod +x start.sh && ./start.sh

# либо без скрипта:
python -m bot.server
```

3. Откройте в браузере: http://127.0.0.1:8765

Дополнительных пакетов ставить не нужно — только Python 3.

## Загрузка свечей в SQLite

```bash
python -m bot
```

Команда сохраняет закрытые свечи в `data/market.db` и печатает последние пять.

## График

```bash
python -m bot.server
```

Страница открывается на http://127.0.0.1:8765. На ней спот и фьючерсы USDT-M, таймфреймы от 1 минуты до 1 месяца. Свечи и объём рисует библиотека TradingView Lightweight Charts, источник котировок — Binance.
